# 中文技术文档适配

Google 风格指南是针对英文写的。写中文文档时，沿用其中与语言无关的原则：读者导向、简洁直接、主动语态、条件在前、内容不过时、可访问、包容。与英文语法相关的规则（sentence case、serial comma、"a / an"）不适用，改用下面的中文排版规则。

## 排版

| 规则 | 正确 | 错误 |
|---|---|---|
| 中文和英文之间加一个空格 | 使用 Docker 部署 | 使用Docker部署 |
| 中文和数字之间加一个空格 | 保留 30 天 | 保留30天 |
| 数字和单位之间加空格；度数和百分比除外 | 10 GB、50% | 10GB、50 % |
| 中文句子里用全角标点 | 完成后，点击 **保存**。 | 完成后,点击 **保存**. |
| 全角标点和英文或数字之间不加空格 | 运行 `make`，然后…… | 运行 `make` ，然后…… |
| 整句都是英文，或者是代码时，用半角标点 | Run `make test`. | |
| 数字用半角 | 3 个节点 | ３个节点 |
| 不重复使用标点 | 完成了！ | 完成了！！！ |
| 专有名词保持官方大小写 | GitHub、Kubernetes、iOS | github、kubernetes、IOS |
| 省略号用 `……`，破折号用 `——` | | |
| 引号用直角引号「」或弯引号 ""，全文统一 | | |

## 用词

| 避免 | 改用 | 对应的英文规则 |
|---|---|---|
| 只需、简单地、轻松、很容易、马上就能 | 删除 | simply / easy |
| 请注意、需要注意的是 | 删除，直接陈述；必要时改用提示框 | please note |
| 目前、现在、最新、即将、敬请期待、新版 | 删除，或者写明版本号或日期 | timeless |
| 上面、下面、上方、下方、左侧、右侧（指代文中位置） | 前面的、以下、下列 | above / below |
| 点击这里、点此、详见此处 | 写出目标页面的标题作为链接文字 | click here |
| 白名单、黑名单 | 允许名单、拒绝名单（或许可列表、阻止列表） | allowlist / denylist |
| 主从、master/slave | 主实例 / 副本（primary / replica）、控制节点（controller）、领导者（leader），按场景选择 | inclusive |
| 杀掉进程 | 停止进程、终止进程（描述 `kill` 命令本身时除外） | kill |
| 等等、之类（在列举末尾） | 列全，或者写"包括……" | etc. |
| 我们（指作者） | 你（指读者）；全文统一用"你"或统一用"您" | second person |
| 被……（被动句） | 改成主动句 | active voice |
| 进行设置、进行安装 | 设置、安装 | 简洁 |

## 结构用语对照

参照 Google Cloud 中文文档的惯例：

| 英文 | 中文 |
|---|---|
| Before you begin | 准备工作 |
| Objectives | 目标 |
| Costs | 费用 |
| Clean up | 清理 |
| What's next | 后续步骤 |
| Troubleshooting | 问题排查 |
| Overview | 概览 |
| Prerequisites | 前提条件 |
| Replace the following: | 替换以下内容： |
| The output is similar to the following: | 输出类似于以下内容： |
| For more information, see … | 如需了解详情，请参阅…… |
| Optional: | 可选： |

## 标题

- 任务类标题以动词开头，例如"安装 CLI""创建集群"；概念类标题用名词短语，例如"认证机制概览"。
- 标题末尾不加标点；不用"第一步、第二步"表示顺序，顺序交给编号列表。
